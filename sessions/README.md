## Agent coordination rules

1. **Claim** work in `AGENT.md` when you start a multi-step task
2. **Update** "Recent completions" + clear your claim when done
3. **Commit** `AGENT.md` with your other changes so the next agent sees it
4. **Don't** rely on chat history — the repo is truth

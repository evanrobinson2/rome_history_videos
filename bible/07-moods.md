# Moods

Status: **Step 1 complete. Step 2 complete — mood presets and palettes defined. Step 3 in progress.**

The base aesthetic is fixed (`02-style-bible.md`): cut paper, silhouette figures,
four colours, light as flat shape. Moods are how that single style produces
emotional range without becoming a different style.

---

### Notes on the list

- **Fury and Terror are different moods and must look different.** Fury is chosen;
  Terror is suffered. Collapsing them would flatten the second half of the film.
- **Humiliation is the load-bearing one.** It is the causal hinge of the whole
  story, and it is the hardest to draw. If the aesthetic cannot do humiliation, the
  audience will not believe the revolt.
- **Procedure and Hubris must not be drawn as villainy.** They are ordinary
  institutional states. That restraint is what makes the outcome disturbing.
- **Dread has no visible antagonist.** The Huns should probably never be shown
  clearly. Dread is an absence mood.

## Step 2 — Mood presets

The base style holds constant (`02-style-bible.md`). A mood is a fixed preset of the
nine variables that remain free. A frame card names a mood and inherits all nine
settings — the same way it inherits a location or a costume.

### Base palette (constant)

Four colours, rigidly held. Moods **re-weight** them; they do not introduce new hues.

| Token | Hex | Role |
| --- | --- | --- |
| **Indigo** | `#1B2A4A` | Sky, deep shadow, night, cold distance |
| **Bone** | `#E8DFD0` | Paper ground, pale earth, dust haze, exposed skin of the substrate |
| **Iron** | `#5C6168` | Stone, cloth, wood, neutral mass, figures in silhouette fill |
| **Gold** | `#B8954A` | **Light and heat only** — sun wedge, fire, lamp flame. Never ornament, never terrain scatter |

Gold allowance is expressed per mood as **none / trace / low / moderate**. Moderate
still means scarce — one wedge, not a wash.

### Preset table

| Variable | Range |
| --- | --- |
| Palette weighting | which of the four dominates; how much gold (if any) |
| Light shape | wide soft wedge / narrow hard shard / diffuse / none |
| Layer count | many (space, air, calm) vs few (compression, threat) |
| Edge quality | clean cut vs torn deckle |
| Shape language | curved and rounded vs angular and shard-like |
| Horizon | high (weight, entrapment) vs low (exposure, sky) |
| Symmetry | broken by default; centred only when ceremony is earned |
| Figure density | isolated silhouette vs mass vs crowd-as-band |
| Negative space | generous vs crowded |

### A. Pressure — before Rome

#### 1. Dread
*Hunnic rumour; a threat never clearly seen.*

| Variable | Preset |
| --- | --- |
| Palette | **Indigo 55%** / iron 30% / bone 15% / gold **none** |
| Light | none — flat overcast, no source |
| Layers | few — foreground presses forward, background lost in same tone |
| Edges | torn deckle on horizon and tree lines |
| Shapes | angular, shard-like silhouettes |
| Horizon | high — sky a thin band, land heavy |
| Symmetry | broken |
| Figures | isolated or absent — dread is an absence mood |
| Negative space | crowded at bottom, empty only as threat-gap |

#### 2. Uprooting
*The decision to abandon home.*

| Variable | Preset |
| --- | --- |
| Palette | **Bone 40%** / iron 35% / indigo 25% / gold **trace** (dawn rim only) |
| Light | wide soft wedge from behind the host, low on the horizon |
| Layers | many — wagons, bundles, livestock in separated planes |
| Edges | clean cut on objects, torn deckle on road and verge |
| Shapes | curved — rounded wagon arches, bundled forms |
| Horizon | low — much sky, exposure on the open road |
| Symmetry | broken |
| Figures | mass moving in one direction, not individuals |
| Negative space | generous ahead on the road — the unknown |

### B. Supplication — the Danube

#### 3. Petition
*Asking Rome from a position of weakness.*

| Variable | Preset |
| --- | --- |
| Palette | **Bone 45%** / iron 35% / indigo 20% / gold **low** (Roman interior light from one side) |
| Light | narrow wedge from a high window or doorway — privilege enters from off-frame |
| Layers | few — interior compresses the petitioner |
| Edges | clean cut throughout — Roman order vs Gothic dishevelment via shape, not line quality |
| Shapes | mixed — Roman architecture angular; Gothic figures curved, diminished |
| Horizon | high — ceiling and lintel weight |
| Symmetry | centred only if the room architecture demands it; subjects off-centre |
| Figures | isolated — two emissaries against a large empty floor |
| Negative space | generous Roman floor between viewer and subjects |

## Step 3 — Mood proofs

One test image per mood, same aesthetic, to verify the presets actually read as
distinct emotions rather than as the same picture in different colours.

### Recommended iconic proof scene

**MAR-GATE-INT-01 — Gate interior looking out.**

Two late-Roman infantrymen as featureless dark silhouettes at the left and right
frame edges, seen from behind, holding spears and oval shields. Through the stone
arch: the vast Gothic host — wagons, livestock, cooking smoke, families stretching
to the horizon on a dirt road.

Why this scene for the first mood proof:

1. **Already load-bearing.** It is benchmark subject 3 (Gothic host) and the
   project's established parallax set piece (`04-locations.md`, `style-benchmark.md`).
2. **Scale in one frame.** Principle 3 — enormous and legible without a cut.
3. **Boundary drama.** Roman stone vs Gothic road; inside vs outside; the gate as
   the hinge of the whole Marcianople pilot.
4. **Mood-flexible.** The same geography reads as **Endurance** (waiting host),
   **Unease** (midday tension), or **Fury** (aftermath smoke) by palette and light
   alone — which is exactly what the mood system must prove.
